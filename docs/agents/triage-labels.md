# Triage Labels

The skills speak in terms of five canonical triage roles. This repo's issue tracker uses the role
names verbatim as its label strings, so a skill that asks for a role can apply it directly.

| Label             | Meaning                                  |
| ----------------- | ---------------------------------------- |
| `needs-triage`    | Maintainer needs to evaluate this issue  |
| `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent` | Fully specified, ready for an AFK agent  |
| `ready-for-human` | Requires human implementation            |
| `wontfix`         | Will not be actioned                     |

All five exist in `endziu/0xChat`. If a role ever diverges from its label string here, record the
mapping in this table rather than guessing at the tracker.
