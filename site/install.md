# Install the app

0xChat is a web app you can install so it opens in its own window, like a native app. Installing
is optional, but it is required for notifications on iPhone and iPad.

## Android, Chrome and Edge

Use the **Install** button in the banner near the top of 0xChat, or open the browser menu and
choose **Install app** (or **Add to Home screen**).

## iPhone and iPad

1. Open 0xChat in Safari.
2. Tap **Share**.
3. Tap **Add to Home Screen**.

## Your key in the installed app

The installed app may keep its own storage, separate from the browser tab you used before. If you
already have an identity in the browser, [export your key](./your-key.md#back-up-your-key) and
import it in the installed app.
