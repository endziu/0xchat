# What is 0xChat?

0xChat is a chat app with private messages that disappear after a set time. You don't need to
sign up or share an email address or phone number.

Open the app and you're ready to chat. It creates an **address** for you: a string of letters and
numbers starting with `0x`. Share your address, conversation link or QR code so people can
message you.

## How it works

- **Your address is how people find you.** Anyone who has it can message you, with no friend
  request needed.
- **Your messages are encrypted.** Your browser locks each message before sending it, so the
  server that delivers it cannot read its contents. This is called end-to-end encryption.
- **Messages disappear.** You choose how long each message stays after the other person opens
  it, from 5 seconds to 24 hours. Unopened messages are deleted 24 hours after sending.
- **You can chat in your browser.** You can also add 0xChat to your home screen for easier access.

## Do I need to know about crypto?

No. 0xChat uses the same kind of addresses as Ethereum, a cryptocurrency network, but you don't
need cryptocurrency or a crypto wallet to chat. There are no transaction fees, and your chats
are not published to a blockchain, the public record used by cryptocurrency networks.

## Keep it or use it once

The app saves a secret code called a **private key** in your browser. Keep it secret, and
[back it up](./your-key.md#back-up-your-key) if you want to keep using the same address.
Without the key, there is no way to recover the account.

Creating a new address is quick and free. You can use 0xChat as a throw-away account:
chat, then [burn your identity](./your-key.md#burn-your-identity) when you're done.
You only need a backup if you want to keep the account.
